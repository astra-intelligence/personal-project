# Security Policy

## Supported versions

Only the latest version of the website, built from the `main` branch, is supported. Fixes are
never backported.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public issues, pull requests or
discussions.**

Report them privately through
[GitHub private vulnerability reporting](https://github.com/pminuca/personal-project/security/advisories/new).

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce it, or a proof of concept.
- The affected page, file or dependency.

## What to expect

- An acknowledgement of your report within 7 days.
- Updates on the progress of the fix, and credit in the published advisory if you wish.
- Please give a reasonable amount of time to fix the issue before disclosing it publicly.
