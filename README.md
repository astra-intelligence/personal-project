# Personal Project

Personal portfolio website showcasing my academic journey, projects and technical skills.

> **Status:** in early development. Progress is tracked publicly on the project board and
> in the [milestones](https://github.com/pminuca/personal-project/milestones).

## About

A fully static website, built from scratch as a complete end-to-end engineering project:
architecture, frontend, containerization, CI/CD and deployment, all following professional
best practices with a strong focus on security, accessibility and performance.

## How this project is developed

- Every change starts as an issue, is developed on its own branch and is merged through a pull
  request into a protected `main` branch.
- Commits are signed and follow [Conventional Commits](https://www.conventionalcommits.org/).
- Coding standards, the Git workflow and the definition of done are documented in
  [`CLAUDE.md`](CLAUDE.md).

## Security

Please report vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md).
